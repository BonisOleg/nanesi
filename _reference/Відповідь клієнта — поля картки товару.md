# Відповідь клієнта — поля картки товару

Джерело: NANESI (замовник). Контекст: відповідь після карти сайту v4.  
Дата фіксації: 2026-08-26.

Статус: збережено для подальшої роботи (імпорт / картка товару / тестове наповнення).

---

Так, окрім опису та ціни можу надати:

- назву товару;
- бренд;
- артикул / SKU;
- категорію та підкатегорію;
- об’єм;
- актуальну ціну;
- стару ціну / знижку, якщо є;
- наявність;
- країну виробництва;
- тип шкіри;
- проблему / призначення;
- активні компоненти;
- склад INCI;
- спосіб застосування;
- опис товару.

Для тестування можу надати декілька товарів з максимально різними характеристиками, щоб одразу перевірити, як буде виглядати повноцінна картка товару.
