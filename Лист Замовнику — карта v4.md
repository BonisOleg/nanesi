### Зафіксували

- Бренд і позиціонування: мультибрендовий інтернет-магазин косметики; корейська косметика — один із напрямів, не обмеження всього сайту. Логотип підключаємо в шапку; заміна через адмінку без переробки верстки.
- Каталог: імпорт Excel/CSV з оновленням за артикулом; закупівельна ціна й залишок — з файлу; **ваша роздрібна ціна імпортом не змінюється**; у кожного товару — постачальник.
- На здачу функціоналу — 15–20 тестових товарів; перед відкриттям магазину — масовий імпорт повного асортименту.
- Повний особистий кабінет (телефон та/або email): обране, замовлення, «повторити», збережене відділення Нової Пошти. Оформлення замовлення **без обов’язкової реєстрації**.
- Відгуки з фото, модерація, позначка «Підтверджена покупка».
- Блог з адмінки; popup збору email (увімк/текст/знижка з адмінки, без повторного показу після закриття або підписки); Instagram — посилання й блок переходу, без автострічки постів.
- Доставка: Нова Пошта + Укрпошта. Оплата: картка онлайн (сервіс узгодимо), післяплата, за реквізитами; способи вмикаються в адмінці.
- Замовлення — у адмінці сайту та **автоматично в SalesDrive**.
- Мови **українська, російська, англійська** — на одній схемі (маршрути, поля, перемикач). Усі три увімкнені на старті; в адмінці можна вимкнути ru або en без участі розробника.
- SEO-посадкові: конструктор у адмінці (адреси, meta, текст, добірка товарів, index/noindex). Конкретні сторінки й тексти — окремо, пізніше.

### Не в першій здачі (технічні закладки вже передбачаємо)

Автолисти покинутого кошика, програма лояльності, персональні рекомендації «під клієнта», живий API постачальника, кілька постачальників на один артикул у кабінеті менеджера.

### Коли зручно — від вас

1. Приклад Excel/CSV від постачальника (з колонками).  
2. Доступ / API SalesDrive.  
3. Ключі Нової Пошти; вибір платіжного сервісу (LiqPay / WayForPay / інший) і ключі мерчанта.  
4. Тексти сторінок «Про нас», «Доставка і оплата», оферта, політика (uk / ru / en — за наявності; інакше заповнимо uk і залишимо поля для перекладу).  
5. ID Google Analytics 4, GTM, Meta Pixel, TikTok Pixel — коли будуть кабінети.
